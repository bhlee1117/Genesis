Construct specification

Type in a part box to search the inventory for that feature type. Picking a suggestion pins that exact part by id (shown as a pinned # chip); clear the box or the chip’s × to let the planner choose. A row marked fusion is a multi-protein CDS: open it with → (or the split button) to pin one of its proteins instead. A Cre-lox row picks an arrangement (DIO, FLEX, FAS or DO) and brackets the coding modules below it — the ones it encloses — until the first module that is not one of CDS, trafficking_motif, linker, p2A, tag or IRES. The bracket is only a picture of what the server does; the modules stay one flat, ordered list.
